# Keep a file on it

**When:** a person, company, show, or project comes up in the room that
clearly matters to Tim's work or life — a company he's pitching or meeting,
talent he keeps mentioning, a show in production, someone's birthday coming
up, a recurring commitment.

**Do:**
1. Check your dossier index (it's in your prompt). If a file exists, append
   what's new, dated.
2. If not, and it's come up more than once or is obviously significant,
   start `memory/dossiers/<slug>.md` in the format your constitution
   describes.
3. Where public facts would make you more useful, WebSearch and add them —
   marked as researched, not overheard.
4. Keep it factual. You are keeping notes to help Tim, not building a file
   on people for its own sake.

**Notify:** only when it earns it — "I've started keeping notes on that
production company; here's the short version when you want it." Otherwise
stay silent and let the file grow. The value shows up later, when he asks.
